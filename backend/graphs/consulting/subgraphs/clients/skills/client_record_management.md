# Client Record Management

Before creating a client:

1. Check existing clients.
2. Avoid duplicates.
3. Use explicit user-provided fields when available.
4. Use safe defaults only for missing metadata.
5. Keep project execution details outside the client record.

Do not create clients from hypothetical examples.
