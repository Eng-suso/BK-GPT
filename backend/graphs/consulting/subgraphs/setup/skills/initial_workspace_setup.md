# Initial Workspace Setup

Use this only when the user clearly asks to create or register real workspace records.

Procedure:

1. Check existing clients and projects first.
2. Create the missing parent record before child records.
3. Keep defaults conservative when metadata is missing.
4. Create process stubs only when the user names a real process.
5. Add sources or decisions only when the user provides them as real context.
6. Stop at setup and route detailed execution to the proper macro agent.
