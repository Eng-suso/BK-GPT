# Workspace Status Synthesis

When summarizing workspace status:

1. Read only the workspace records needed for the answer.
2. Separate active work, blocked work, and missing information.
3. Prefer a short list of high-leverage next actions.
4. Name the owner or destination scope when clear.
5. Do not invent project status that is not present in workspace records.
