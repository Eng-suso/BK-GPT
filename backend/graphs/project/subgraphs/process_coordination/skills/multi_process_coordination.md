# Multi Process Coordination

## Purpose

Use this skill when the project includes several processes that must be mapped, compared or sequenced together.

## Method

1. Read the project process map and readiness matrix.
2. Identify processes that are incomplete, blocked or ready.
3. Identify shared actors, sources, decisions and likely dependencies.
4. Recommend focus order and interview needs.
5. Prepare handoff to Process Macro for deep work on one process.

## Output

Return a project-level workplan, not a detailed AS-IS model.
