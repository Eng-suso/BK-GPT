# Process Dependency Mapping

## Dependency Types

- Upstream/downstream process dependency.
- Shared actor or owner.
- Shared document, data object or system.
- Decision dependency.
- Interview or evidence dependency.

## Rule

When no explicit dependency table exists, label dependencies as hypotheses and state what evidence would confirm them.
