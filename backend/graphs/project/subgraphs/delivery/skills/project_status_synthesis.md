# Project Status Synthesis

## Checklist

- Current phase and status.
- Progress and whether it matches evidence.
- Next step and whether it is specific.
- Open issues and decisions.
- Delivery risks and blockers.
- Concrete actions for the consultant.

## Rule

Do not invent progress. If progress is not supported by project context, label the update as a recommendation.
