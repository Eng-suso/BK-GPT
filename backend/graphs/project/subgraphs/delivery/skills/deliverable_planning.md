# Deliverable Planning

## Method

1. Identify expected deliverables from the project snapshot.
2. Check which processes, sources or decisions each deliverable depends on.
3. Mark missing inputs.
4. Produce a short plan with sequence, owner and next action.

## Guardrail

If a deliverable depends on several processes, ask Process Coordination to build the dependency-aware workplan.
