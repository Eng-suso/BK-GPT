# Project Delivery Governance

## Purpose

Use this skill for project delivery status, planning, risks, blockers, milestones and deliverables.

## Method

1. Read the project delivery brief or use the preloaded snapshot.
2. Separate confirmed workspace facts from recommendations.
3. Identify status, progress, next step, blockers and delivery risks.
4. Prepare a status update, deliverable plan or next-action list.
5. Route multi-process dependency questions to Process Coordination.

## Output

Return a compact operational summary with owner and next action for each important item.
