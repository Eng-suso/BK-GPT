# OMG BPMN 2.0.2 XML Schemas

These five XSD files are the BPMN 2.0.2 schemas already used by
`tests/evals/bef4llm_xsd`, copied here so the runtime write gate does not
depend on test files. Their authoritative publication is the
[OMG machine-readable specification](https://www.omg.org/spec/BPMN/machine-readable).

The runtime copies normalize line endings, indentation and trailing whitespace
only. Keep their XML content identical to the evaluation copies until they can
share a single packaged resource.
