# Consulting Delivery

## Purpose

Use this skill to manage a consulting engagement from unclear request to useful deliverable.

## Operating Procedure

1. Clarify the engagement objective.
2. Define scope, constraints, stakeholders, and expected output.
3. Identify the current phase: discovery, analysis, synthesis, recommendation, alignment, or delivery.
4. Choose the relevant process skill for the current phase.
5. Separate confirmed facts, assumptions, hypotheses, and open questions.
6. Convert findings into a decision-ready synthesis.
7. Recommend next actions with owner, rationale, and expected outcome when possible.
8. Produce the deliverable in the format the user needs.

## Rules

- Do not force every consulting task into BPMN.
- Do not jump to recommendations before the situation is understood.
- Keep advice specific to the user's current business context.
- Prefer a small number of high-leverage next steps over broad generic plans.
- State assumptions explicitly when evidence is incomplete.

## Output Pattern

When useful, structure the answer as:

- objective
- current understanding
- confirmed facts
- assumptions or risks
- recommended next steps
- deliverable or draft output
