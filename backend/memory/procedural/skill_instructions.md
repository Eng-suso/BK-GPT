# Consultant Procedural Skills

This registry defines the Markdown skills that make up the DeliR Consultant Operating Brain.

The goal is to keep procedural memory at the level of reusable consulting methods, not one-off facts or project details.

## Skill Set

1. `skills/consulting_delivery.md`
   - Use for engagement framing, work planning, synthesis, recommendations, stakeholder alignment, and deliverables.

2. `skills/consultant_memory_governance.md`
   - Use for deciding whether information belongs in semantic, episodic, or procedural memory.

3. `skills/process_discovery.md`
   - Use for reconstructing a business process from fragmented evidence.

4. `skills/evidence_synthesis.md`
   - Use for converting interviews, notes, documents, and observations into supported claims, hypotheses, contradictions, and gaps.

5. `skills/process_modeling.md`
   - Use for moving from validated process knowledge to BPMN-ready process structure.

6. `skills/process_analysis.md`
   - Use for diagnosing the confirmed As-Is process.

7. `skills/process_redesign_validation.md`
   - Use for designing To-Be options, validating them, and approving the process baseline.

## Sequencing Rule

For process-consulting work, use this default sequence:

1. Process Discovery
2. Evidence Synthesis
3. Process Modeling
4. Process Analysis
5. Process Redesign and Validation
6. Consulting Delivery

Use `consultant_memory_governance.md` throughout whenever the task involves saving, retrieving, classifying, or updating memory.
