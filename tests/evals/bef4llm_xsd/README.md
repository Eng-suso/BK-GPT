# Schema XSD di BPMN 2.0

Gli schemi ufficiali OMG di BPMN 2.0 (`BPMN20.xsd` e i file che include), presi
da [bpmn-io/bpmn-moddle](https://github.com/bpmn-io/bpmn-moddle/tree/main/resources/bpmn/xsd),
la stessa fonte che BEF4LLM usa per la validita' (`Q_val`). Copiati senza
modifiche: `tests/evals/bef4llm.py` li carica da qui, senza rete.
